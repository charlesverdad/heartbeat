Waiting & loading

Animations for the in-between moments: loaders for when something is on its way, countdowns for the five minutes before the service, and holding screens for the livestream.

Click any animation to replay it. The countdowns are real five-minute timers; they open near the end so you can see how each one lands. Use the buttons under them to jump around.

Part one

Countdowns

Each one is 5:00 of video and then about five seconds that land on the logo, so start it exactly five minutes before the service and it hands over on time. Rendered at 16:9 for the screens and the stream. Every countdown beats once a second, the same rhythm as the heart in the name.

Part two

Loaders

Short seamless loops for “something is on its way”: a slow stream, a video about to play, a page loading on the website. Five use only the mark; the last one uses the lockup. Each also comes as a small looping GIF for web pages.

Part three

Holding screens

Seamless loops for the livestream and the room. The backdrop has no text, so it can sit behind ProPresenter’s own countdown timer or an announcement.

Using them

Where each one goes

ProPresenter

  • Countdown video: add it as a video cue set to play once and stop on the last frame. Trigger it at exactly five minutes to start; it ends on the logo.
  • Prefer a live timer? Put the holding backdrop on the background layer, set to loop, and run ProPresenter’s countdown timer as text over the clear side.
  • Loops (holding screens, loaders) are seamless: set the cue to loop.

Livestream

  • Before going live: Starting soon, then switch to a countdown for the last five minutes.
  • Technical problem or break: Be right back. If the encoder is up but the picture is not, a loader on its own works too.

Website and app

  • Loaders come as small looping GIFs, on black and on white, in logo-motion/out/gif/.
  • Need another length of countdown, such as 10:00? It is one line in anims-v3.js; see the comment at the top.
In the repo

brand/logo-motion/src/anims-v3.js holds these animations. Render one with npm run motion -- --only countdown-ring-5m. Earlier rounds are unchanged in report.html and report-v2.html.
